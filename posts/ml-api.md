AI and Machine Learning are completely transforming the technology landscape. However, for many developers, standard frameworks like TensorFlow or PyTorch feel like black boxes. In this project, we are going to build a Multilayer Perceptron (MLP) Neural Network strictly from scratch in Java!

### The Architecture

Our engine will support dynamic layers, varied activation functions (Sigmoid, ReLU, Tanh), and standard backpropagation with a configurable learning rate. The real fun part starts when we attempt to train our custom-built neural network on the classic MNIST dataset to correctly identify handwritten digits with high accuracy.

<hand-quote author="AI Enthusiast">
  The math isn't magic. It's just matrix multiplication and clever calculus mapped out over thousands of variables.
</hand-quote>

This API will later be integrated directly into a drawing application via WebSockets!
